# Contra

Use Start to open the title menu. Select chooses 1 Player or 2 Players; Start begins the game. Arrow keys move, Z jumps and X fires.

Invite a friend to play: the host controls player one, and the invited player controls player two. Select the two-player mode in the game for both characters. Watch invitations provide viewing without controls.

Pause, Resume, Reset, Unload and switching cartridges stay on the same arcade page. Original Contra has no battery save; save-anywhere snapshots are not supported.
