The Legend of Zelda: A Link to the Past

Select the cartridge, then Start + audio. Focus the game screen for keyboard controls.
Arrow keys move. Z = B, X = A, A = Y, S = X, Q/W = L/R, Shift = Select, Enter = Start.
Standard gamepads and touch controls are supported. Pause or switch away to release controls.
Save game and Load game store one private checkpoint in this browser. Battery saves persist separately.
This is a single-player game. A play invitation shares control of the same hero; it does not add a second character.
