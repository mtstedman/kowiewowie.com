# Shared NES engines and cartridges, contract 1

The updater reads the immutable authoring/shared-engine-cartridges-20261115 snapshot and writes only a new, isolated output directory. It rejects an existing output directory and never modifies the snapshot or active definitions.

Engine ABI: a versioned engine exports createMachine(cartridge, options), retaining the existing host-facing machine interface, reset, any existing dispose method, and battery interfaces. Cartridge exports are metadata, blocks, prgHex, chrHex, trainerHex and requirements. Requirements match ABI, mapper, board, battery, NTSC region and compiler revision. The engine owns CPU/PPU/APU, devices, mapper, timing, machine state and compiled-Wasm cache. The cartridge supplies injected translated program factories, immutable original ROM bytes and board/mapper/RAM/battery metadata. Each call allocates independent mutable machine state, WebAssembly.Memory and instances. Only immutable code and compiled WebAssembly.Module objects may be shared. Translated bank source bytes remain unchanged. Engine selection uses declared ABI and capabilities, never cartridge title. Legacy, MMC3, timed MMC1 and owned UxROM execution generations remain explicit variants; incompatible combinations fail explicitly.

Output paths, relative to the isolated output directory:
- CONTRACT.md: this authored contract.
- htdocs/games/engines/nes/<release>/<variant>/: extracted reusable implementation modules and engine-manifest.json.
- htdocs/games/engines/nes/<release>/release.json: exact engine module closure and variant capabilities.
- htdocs/games/engines/nes/registry.json: versioned release selection authenticated by package bindings; no unpinned mutable runtime selection.
- htdocs/games/<id>/cartridge/: unchanged translated bank files and cartridge.mjs; data.mjs exports frozen metadata/blocks and PRG/CHR/trainer hex; pure-data entry.mjs re-exports data plus frozen ABI/capability requirements. cartridge-manifest.json describes these requirements and provenance. Optional authenticated source.nes is included only when available. This entire tree is independent of engine release selection.
- htdocs/games/<id>/composition-entry.mjs and composition.json: selected engine imports, binding receipts and executable source maps outside cartridge/. game-package.json keeps game-package/1; its files inventory authenticates cartridge, selected engine and composition closures. Existing optional network-package.json envelopes and both mandatory network catalogs carry the composed artifactDigest. Missing legacy envelopes are never generated.
- htdocs/games/arcade/: authored package authentication and worker/host integration updates, preserving shared presentation and transport.
- includes/api/classes/NetplayPolicy.php and netplay-catalog.json: coherent server policy and authenticated package identities at their original relative paths.
- receipts/source-pins.json, receipts/integrity.json and compatibility-audit.json: original hashes, transformation receipts and per-cartridge compatibility evidence.
- tests/shared-engine-regression.mjs: emitted extraction, authentication, isolation and behavioral regression checks.

The package remains game-package/1 with host API1 and its existing exact fields. Engine binding and executable source maps live in an inventoried composition sidecar outside cartridge/. Authentication binds cartridge files and the selected transitive engine JS/Wasm closure to package and netplay identity. Runtime imports must use authenticated bytes or an equally strict existing immutable loader; checking a URL and later importing mutable bytes is insufficient. Metadata refresh deterministically rebuilds bindings after engine release selection without editing cartridge program source. Historical source authentication remains intact.

Draft/static validation is not runtime execution. Emitted regressions and baseline equivalence remain root gates until actually run. No performance claim, deployment, activation or concurrent timing is part of this updater.

Authentication boundary: package.mjs and authenticated-loader.mjs are trusted same-origin host bootstrap, outside composition.moduleGraph. package-contract.mjs retains dependency-neutral validation and primitives; executable imports are redirected to it. Only the bootstrap dynamically imports the authenticated Blob entry. Executable cycles and dynamic imports remain rejected. All inventory bytes, binding receipts and source spans remain authenticated. Node consumers import composition-entry.mjs directly from the isolated, verified candidate; Blob execution is a browser path.

Bank admission recognizes the pinned generated declaration, bank assignments, instruction closures and exact recursive-freeze suffix. An optional fourth tuple field is a literal prefetched-byte count from 1 through the source-byte length; it is never a bit mask. Original instruction bytes, functions and runtime deferred fetches remain unchanged. Source copying is limited to htdocs/, includes/, tests/, deploy/, package.json and tsconfig.json; other outputs are explicitly generated. Closure traversal rejects every intentionally removed original before reading or restoring it. It proves supported module construction only; instruction bodies remain authenticated compiler code, not a general JavaScript sandbox. Private engine ownership checks remain in the extracted bodies.

The candidate nginx config scopes Blob script/worker permission to the seven game route prefixes and arcade. Other routes retain the original CSP. No unsafe-inline, unsafe-eval, wildcard or external script permission is added. This is required configuration, not a deployed change. tests/shared-engine-browser.mjs serves an isolated candidate with these policies and runs Playwright Chromium checks, including blocked Blob policies, all seven authenticated adapter imports and module workers, tamper rejection and Blob cleanup. Run with Playwright resolvable and its Chromium installed. Neither these checks nor nginx validation runs during drafting.
