Keyboard: arrows, Z = A, X = B, Shift = Select. Game Start / Enter resumes the engine and presses controller Start. Engine start / resume runs the engine without pressing Start. Audio starts when available. Quick taps wait for a frame; repeated taps play in order. Overlapping controls hold a button until all are released. Input buffering is limited: a full buffer stops the preview and asks for Reset. Pause, Reset, focus loss and hiding the page clear all input.

Experimental hardware integration. Unsupported operations stop with a visible error.
