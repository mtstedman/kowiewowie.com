## Arcade saves and sharing

Choose Slot 1, Slot 2, or Slot 3 to save your position on this browser. Autosave updates once a minute while playing. Loading a save first stores your current position in Before last load, then leaves the game paused; use Resume to continue. Existing saves are imported into Slot 1 without deleting the original. Battery saves remain separate.

The host owns saves for the whole game, including both players. Guests and viewers run synchronized copies without changing their personal saves. Player connections prefer a direct route with relay fallback; viewers use the relay. An absent second player sends no input, so keep a two-player game paused until they join if their character needs protection.

Super Mario World

Select the cartridge, then Start + audio. Focus the game screen for keyboard controls.
Arrow keys move. Z = B, X = A, A = Y, S = X, Q/W = L/R, Shift = Select, Enter = Start.
Standard gamepads and touch controls are supported. Pause or switch away to release controls.
Choose a saved-position slot to save or load. Battery saves persist separately.
Choose 2 PLAYER GAME in the game menu. Mario and Luigi take turns. A second local controller handles Player 2; a play invitation assigns the remote guest Player 2.
