# Commander Keen: Marooned on Mars

Start + audio begins the game. Click the screen to focus the keyboard. Space dismisses the title; Enter confirms menu choices. Arrows move, Ctrl jumps or enters a level, Alt uses the pogo stick, Ctrl + Alt fires, and Esc opens the menu. The control buttons below the screen work with touch.

Pause/Resume preserves this running session. Reset starts a fresh machine. Leaving the game discards its drive state; saved positions and persistent saves are not supported. Sharing is unavailable.
