# Donkey Kong Country

Start + audio, then click the game screen. Arrows move; Z = B/jump, A = Y/run or roll, X = A, S = X, Enter = Start, Shift = Select. The on-screen controller and standard gamepads are supported. Choose a one-player or local two-player mode in the game menu.

The existing SNES save slots and battery storage are available on this browser. Pause/Resume retains the session; Reset restarts the cartridge. Network invitations are unavailable for this addition.
